# contributing

thanks for helping out. see [README.md](./README.md) for project overview.

## setup

```bash
bun install
```

## dev commands

```bash
bun run check     # typecheck -> lint -> fmt check
bun run test      # workspace tests
bun run build     # workspace builds
bun run dev       # plot server + web app
```

individual checks:

```bash
bun run typecheck
bun run lint
```
